# Compliance Check Validation Checklist

- [ ] All selected standards have been evaluated
- [ ] Every requirement has a status (Compliant/Non-Compliant/Partial/N/A)
- [ ] Compliant items have evidence references
- [ ] Non-compliant items have specific remediation steps
- [ ] Overall compliance score calculated per standard
- [ ] Non-compliant items prioritized for remediation
- [ ] Report written to governance folder
