# Stage Validation Checklist

## Pre-Validation
- [ ] State file loaded and current stage identified
- [ ] Correct gate criteria loaded for current stage
- [ ] All referenced artifact files checked for existence

## Validation Execution
- [ ] Each criteria evaluated with clear PASS/FAIL
- [ ] Evidence provided for each evaluation
- [ ] No criteria skipped without explanation

## Post-Validation
- [ ] Validation result logged to audit trail
- [ ] State file updated if gate passed
- [ ] User presented with clear next steps
- [ ] Override reason documented if gate was overridden
