# Content Validation Checklist

## Mermaid Diagrams
- [ ] All diagram types are valid
- [ ] All node references resolve
- [ ] Arrow syntax is correct
- [ ] Subgraphs are properly closed
- [ ] Labels have matching quotes

## Markdown Structure
- [ ] Heading hierarchy is sequential
- [ ] All internal links resolve
- [ ] Code blocks have language specifiers
- [ ] Table columns are consistent
- [ ] List indentation is consistent
- [ ] No orphaned HTML tags

## Content Quality
- [ ] No duplicate sections
- [ ] No unresolved placeholders ({{var}}, [TODO], TBD)
- [ ] All required template sections present
- [ ] No empty sections

## ASCII Diagrams
- [ ] Box borders aligned
- [ ] Connections don't overlap text
- [ ] Readable in monospace font
