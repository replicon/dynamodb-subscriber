# Regression Detection Validation Checklist

- [ ] Current and previous results loaded
- [ ] Every test classified (regression, improvement, persistent, stable, new, removed)
- [ ] All regressions have likely cause identified
- [ ] Regressions have severity assigned
- [ ] Fix recommendations provided for each regression
- [ ] Quality trend calculated across available runs
- [ ] Assessment is honest (not sugar-coated)
- [ ] Action items are prioritized and actionable
