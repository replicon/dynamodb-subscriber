# Coverage Report Validation Checklist

- [ ] Coverage data collected with all metrics (line, branch, function)
- [ ] Per-module breakdown provided
- [ ] Critical gaps identified and prioritized by risk
- [ ] Uncovered error handling paths flagged
- [ ] Uncovered auth/security logic flagged
- [ ] Improvement recommendations are specific and actionable
- [ ] Coverage trend included (if previous data available)
- [ ] Effort estimates provided for reaching targets
